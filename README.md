# ⚡ AuSy - Proximity Auto-Sync Engine

**AuSy** is a smart Android app built with **Kotlin** and **Jetpack Compose** that automatically detects nearby Bluetooth Low Energy (BLE) devices and triggers seamless proximity-based data synchronization.

---

## ✨ Features

* 📡 **Real-time BLE Radar:** Continuously scans for nearby Bluetooth Low Energy devices.
* ⚡ **Proximity Trigger:** Automatically initiates auto-sync when a device comes within close range ($>-60$ dBm RSSI).
* 🎨 **Modern Dark UI:** Clean dashboard powered by Jetpack Compose & Material 3.
* 🔒 **Permission Handling:** Built-in dynamic Bluetooth and Location permission checks for Android 12+.

---

## 🛠️ Built With

* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Material 3)
* **Connectivity:** Android Bluetooth LE API
* **Architecture:** ComponentActivity with Reactive State Management
